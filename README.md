# 痒局长

做 ComfyUI 的小工具。都是自己被卡住了才写的。

**ComfyUI-ModelMirror** —— 缺模型的时候从镜像下，不用等官方那个按钮转圈。

**ComfyUI-ModelSorter** —— 下了模型不知道往哪个目录放。它读文件头判断类型，不猜文件名。

**ComfyUI-ManagerFix** —— Manager 列表拉不到，把地址改成镜像，改完真去拉一遍确认。

三个都是 MIT。
