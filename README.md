没错，我的项目基本都是拿 AI 开发的。我负责说清楚要什么、以及验收；代码是它写的。

目前在做的：

- **AI 严父** —— 面向 AI Agent 的东西。让一个 AI 去管其他 AI，给人类减负。第一次启动会自动布置好，加冕一位 AI 当"严父"，剩下你只跟它说话。程序本身只是个册封台，不干活。

- **9A2Live** —— 分层 PSD 校对。画师交上来几十层，得一层一层对，现在做成能点着看的界面。

- **上上签** —— 漫展现场叫号小程序，带照片打印取号。金签红签彩签分档，过号不作废。

- **世界树娘** —— 数字化生命。

有时候，会把开发过程中一些小巧思做成工具开源：

- **[ComfyUI-ModelMirror](https://github.com/AinJuZen/ComfyUI-ModelMirror)** —— 缺模型时从镜像补，不用等官方那个按钮转圈
- **[ComfyUI-ModelSorter](https://github.com/AinJuZen/ComfyUI-ModelSorter)** —— 下了模型不知道放哪个目录，它读文件头判断，不猜文件名
- **[ComfyUI-ManagerFix](https://github.com/AinJuZen/ComfyUI-ManagerFix)** —— Manager 列表拉不到，把地址改成镜像，改完真去拉一遍确认
